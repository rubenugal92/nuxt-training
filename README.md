# Nuxt 3 Demo — Vue 3 + Composition API + TypeScript + Pinia

## Introducción

Este proyecto tiene como objetivo servir como training para aprender Nuxt js. Para ello se realiza una app/demo funcional que a la vez te va explicando las ventajas de usar Nuxt en un proyecto Vue. 

En este caso, se sube solo el FRONT y el BFF en Nuxt. Está pensado para que luego haya un back-end hecho en la tecnología deseada que por ahora no existe, por eso las peticiones que tienen que ver con el back-end, por ahora no funcionan ya que no es la tónica de este proyecto. 

En este proyecto se usan feats de Nuxt como el auto-import, auto-routing, SSR, BFF etc.
Sirve como una primera toma de contacto.


## Cómo arrancar la app

```bash
cd test-nuxt
npm install
npm run dev
# → http://localhost:3000
```
